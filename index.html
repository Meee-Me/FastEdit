About Fast Edit AI

Fast Edit AI is built from scratch and runs on your device. Nothing is uploaded.

  • Language model: a neural network that reads your request (words and letter patterns, so typos are fine) and picks from 47 editing skills. It has ~100k parameters and is trained in your browser each time the page loads (…).
  • Vision: measures exposure, contrast, clipping and color cast, finds the palette, the subject (where the eye goes), the main light and the horizon.
  • Planner: turns what you asked plus what it sees into edits: adjustments, smart crops, background removal and generated layers.
  • Generators: draws stars, birds, flares, frames, captions, weather and more, placed to fit your photo.

Try: “warmer with a soft vignette”, “crop to 4:5”, “add a caption that says "Hello"”, “remove the background”, “add birds and a moon”.

Connect your agent

Use Fast Edit's own AI, or plug in your own agent. Your choice stays in this browser.

Your endpoint must allow cross-origin requests (CORS) from this site.
Agent protocol
POST <Agent URL>
Authorization: Bearer <token>   (if set)
Content-Type: application/json

{
  "protocol": "fastedit.agent/v1",
  "task": "edit" | "art" | "critique" | "ping",
  "prompt": "full instructions, including the JSON
             shape Fast Edit expects back",
  "image": { "media_type": "image/jpeg",
             "data": "<base64>" } | null
}

Reply 200 with JSON:
{ "text": "<the model's reply, a JSON string>" }
or the requested JSON object itself.
Errors: non-2xx with { "error": "message" }.
